## Add it

In Hayase, open **Settings → Extensions**, paste this link and press **Import Extensions**:

```
https://mirai-ext.pages.dev/index.json
```

> [!TIP]
> The subtitles show up in the player's subtitle menu.

> [!NOTE]
> No subtitles for an episode? Most likely Mirai Anime does not have one for it yet.
