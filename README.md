<h1 align="center">Mirai Anime</h1>

<p align="center">
  Arabic subtitles for anime, right inside Hayase.
</p>

## Add it

In Hayase, open **Settings → Extensions**, paste this link and press **Import Extensions**:

```
https://raw.githubusercontent.com/scigward/Mirai-ext/main/index.json
```

> [!TIP]
> Then play an episode, the subtitles show up in the player's subtitle menu.

> [!NOTE]
> No subtitles for an episode? Most likely Mirai Anime doesn't have one for it yet.
